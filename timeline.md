# Timeline Template

This file tracks the chronological sequence of events in your crime fiction story. Use it to ensure consistency with alibis, evidence, and character movements.

## Instructions

1. List events in chronological order (not narrative order)
2. Include events that happen before the story starts if relevant
3. Track what each major character is doing at key times
4. Note when evidence is created, moved, or destroyed
5. Mark which events readers know about vs. what actually happened

## Format

```
[Date/Time] - Event Description
  - Who: [Characters involved]
  - Where: [Location]
  - Evidence: [Any physical evidence created/affected]
  - Witnessed by: [Who saw/knows about this]
  - Reader knows: [Yes/No/Partially - what do they know?]
  - Notes: [Anything important about timing, alibis, etc.]
```

## Example

```
Tuesday, March 15, 2024

8:00 PM - Victim leaves office
  - Who: Jennifer Ross
  - Where: Downtown office building, heading to parking garage
  - Evidence: Security camera footage, keycard log
  - Witnessed by: Security guard (brief wave)
  - Reader knows: Yes (shown in opening scene)

8:15 PM - Killer follows victim to parking garage
  - Who: [Killer's name - for outline purposes]
  - Where: Parking garage level 3
  - Evidence: Parking stub (shows entry time)
  - Witnessed by: No one
  - Reader knows: No (concealed until revelation)

10:30 PM - Suspect #1 at bar (alibi)
  - Who: Marcus Williams
  - Where: O'Malley's Bar downtown
  - Evidence: Credit card receipt, bartender testimony
  - Witnessed by: Bartender, 3 other patrons
  - Reader knows: Yes (Marcus mentions this in interrogation)
  - Notes: Solid alibi BUT bar is only 5 minutes from crime scene
```
